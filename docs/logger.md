# Getting files off the logger

Use Peach's own software (PowerLine), which saves `.peach-data` files. Everything in this repository starts
from those files.

`peachraw-notes/` describes what we saw in a newer `.peachraw` file from our own logger: a `PEAC`
container, session and logger numbers, 50 Hz sample records of 18 channels, interleaved with other records.
Incomplete.

For anything beyond this, ask Peach for an official export or API.
