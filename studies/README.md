# Studies

- `curves_prototype/`: force and angle curves in a FIT file for the Intervals.icu charts. Prototype, see
  docs/rita-mapping.md. Needs `pip install fit-tool==0.9.14` and the Rowing Data Standard Python library
  (`pip install "git+https://github.com/Rowing-Industry-Trade-Association/rowing-data-standard.git@a6225409#subdirectory=python"`).
- The method comparison in docs/stroke-or-seconds.md can be repeated on your files with `rowtools simulate`.
