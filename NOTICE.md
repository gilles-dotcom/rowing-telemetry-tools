# Third parties

- **fit-tool** (FIT encoding), BSD-style licence, Stages Cycling. Installed as a dependency, not copied.
- **fitparse** (FIT reading), MIT. Dependency.
- **numpy, pandas, requests**: dependencies under their own licences.
- **Rowing Data Standard** (Rowing Industry Trade Association and contributors): the FIT mappings follow the
  specification text (CC BY 4.0) at commit `a6225409`. The specification was not copied into this repository.
  This is not an official implementation and is not endorsed by RITA. The curves prototype uses the
  standard's Apache-2.0 Python library as a dependency.
- **FIT** is Garmin's protocol. Garmin's FIT Protocol License applies to anyone implementing it.
- **Peach**, **PowerLine** and **Peach Realtime** are names of Peach Innovations Ltd. This project is not
  affiliated with, endorsed by or supported by Peach Innovations. The names are used only to say which files
  the tools read.
- The firmware experiment builds with the Adafruit nRF52 Arduino core and UF2 tools; those are not included.
